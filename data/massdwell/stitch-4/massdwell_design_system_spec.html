# MassDwell Hub: Design System Specification This document serves as the official visual and structural reference for the MassDwell Hub internal application. It is designed to ensure consistency across all sales and operations tools. ## 1. Brand Identity & Color Palette The MassDwell brand is defined by a modern, professional, and high-trust aesthetic. | Role | Name | Hex Code | Usage | | :--- | :--- | :--- | :--- | | **Primary** | Deep Navy | `#011832` | Backgrounds, primary text, brand logo, headers. | | **Secondary** | Admiral Blue | `#132C49` | Active states, accents, secondary containers. | | **Tertiary** | Soft Denim | `#445970` | Secondary text, borders, subtle highlights. | | **Background** | Pure White | `#FFFFFF` | Main content area, card backgrounds. | | **Surface** | Ghost Blue | `#F8F9FF` | Subtle section backgrounds, off-white surfaces. | ## 2. Typography We use **Inter** via Google Fonts for all application text to ensure maximum readability and a clean, architectural feel. - **Headlines:** SemiBold/Bold, tight tracking (`-0.02em`), Deep Navy. - **Body Text:** Regular/Medium, standard tracking, Soft Denim for secondary info, Deep Navy for primary. - **Labels/Captions:** Bold, Uppercase, increased tracking (`0.05em`), smaller font size (10-12px). ## 3. Component Architecture ### Navigation Sidebar (Desktop) / Bottom Bar (Mobile) - **Background:** Deep Navy (`#011832`). - **Active State:** Admiral Blue (`#132C49`) background with White text and a left-accent border. - **Icons:** Minimalist, consistent line weight (Material Design icons preferred). ### Data Cards - **Background:** Pure White (`#FFFFFF`). - **Border:** 1px solid `#EEF2F6`. - **Corner Radius:** `8px` (Standard) or `12px` (Large). - **Shadow:** Subtle elevation (`0 2px 4px rgba(1, 24, 50, 0.05)`). ### Interactive Elements - **Primary Buttons:** Deep Navy background, White text, 4-8px border radius. - **Secondary Buttons:** Ghost Blue background, Deep Navy text. - **Input Fields:** Soft Denim borders (1px), 4px radius, focus state uses Admiral Blue. ## 4. Layout Principles - **Grid:** 8px base unit for all spacing and margins. - **Mobile First:** All views are optimized for field use on smartphones. - **Content Hierarchy:** Use bold color blocking for headers and light, airy surfaces for data entry and reading. ## 5. Visual Language - **Cleanliness:** Prioritize whitespace to reduce cognitive load during sales calls. - **Trust:** Use the Deep Navy consistently to ground the interface in authority. - **Precision:** Alignment is critical; all elements should follow a strict grid.
