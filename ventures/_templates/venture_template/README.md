# Venture Template

**This is a template directory for new Moonshot ventures.**

Copy this entire directory to `/ventures/venture_XXX/` when starting a new project.

---

## Quick Start

1. Copy template: `cp -r ventures/_templates/venture_template ventures/venture_XXX`
2. Update `venture_config.json` with venture-specific values
3. Moonshot fills in `PRD.md` and `experiment_plan.md`
4. Follow the Venture Workflow (see below)

---

## Venture Workflow

```
1. Moonshot: Research + write PRD
   → Update venture_config.json
   → Write PRD.md
   → Write experiment_plan.md

2. Clawson: Create Change Request
   → "Approved: codesmith — [venture name]"

3. Codesmith: Write Architecture Plan
   → Define Claude Code tasks
   → Create /app/server.js scaffold

4. Claude Code: Generate Code
   → Implement endpoints/features
   → Write tests

5. Codesmith: Test + Review
   → npm test (7 quality gates)
   → git commit "Claude Code: [task description]"

6. Codesmith: Report Results
   → Document in CHANGELOG.md
   → Report to Clawson with evidence

7. Clawson: Accept + Deploy
   → Update metrics.md baseline
   → Update venture_config.json status
   → Update Mission Control
```

## How to Use

### 1. Create New Venture
```bash
cp -r ventures/_templates/venture_template ventures/venture_001
cd ventures/venture_001
git init
git config user.email "moonshot@openclaw.ai"
git config user.name "Moonshot"
```

### 2. Moonshot: Fill in PRD + Experiment Plan
```bash
# Edit these files:
- PRD.md (product spec)
- experiment_plan.md (hypothesis + metrics)
- venture_config.json (metadata)

git add PRD.md experiment_plan.md venture_config.json
git commit -m "Moonshot: PRD + experiment plan"
```

### 3. Codesmith: Create Architecture
```bash
# Edit app/server.js with architecture plan
# Create CHANGELOG.md entry
git add app/ CHANGELOG.md
git commit -m "Codesmith: Architecture plan"
```

### 4. Claude Code: Generate Code
```bash
# Claude Code generates code in app/, tests/, etc
# Codesmith runs: npm test (all 7 gates)
# If pass: git commit "Claude Code: [task]"
# If fail: git revert, refine, retry
```

### 5. Update Metrics
```bash
# After each major milestone, update:
- venture_config.json (status, metrics.current)
- metrics.md (live tracker)
```

### 6. Deploy
```bash
# Clawson adds secrets to .env
# Codesmith runs: npm start
# Verify: Smoke test all pass
```

## Mission Control Integration

`venture_config.json` feeds into:
- `data/mission-control/venture_work_links.json`
- `data/mission-control/venture_velocity.json`
- `data/mission-control/workstreams.json`

**Fields that sync:**
```
venture_id → workstream_id
name → title
stage → current_stage
status → status
metrics → linked metrics
```

## Key Constraints

### ✅ Allowed
- Edit any files in this venture
- Add subdirectories for app code
- Create new routes/endpoints
- Write tests
- Update documentation

### ❌ Forbidden
- Modify /canon/**, /config/**, /scripts/**
- Access /credentials/ (env vars only)
- Create new agents or routes
- Modify OpenClaw system files
