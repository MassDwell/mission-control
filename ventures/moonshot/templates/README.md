# Moonshot Discovery Templates

This directory contains standardized templates for Moonshot's venture discovery work.

## Opportunity Brief Template

**File:** `OPPORTUNITY_BRIEF_TEMPLATE.md`

### Purpose

The Opportunity Brief is Moonshot's primary output for structured venture discovery. It provides a comprehensive framework for evaluating new business opportunities before significant resources are committed.

### When to Use

Use the Opportunity Brief template when:

- Exploring a new market or customer segment
- Evaluating a potential new product or service
- Responding to a discovery request from leadership
- Proposing a validation experiment
- Documenting research findings that suggest an opportunity

### How to Use

1. **Copy the template** to a new file with a descriptive name:
   ```
   cp OPPORTUNITY_BRIEF_TEMPLATE.md ../briefs/YYYY-MM-DD-opportunity-name.md
   ```

2. **Fill in all sections** with specific, evidence-based information:
   - Start with Executive Summary last (after completing all sections)
   - Use concrete data and citations where possible
   - Mark confidence levels honestly
   - Include specific metrics and targets

3. **Focus on these key questions:**
   - Is the problem real and painful enough?
   - Can we reach the customer economically?
   - Why is now the right time?
   - What's the smallest experiment to validate?
   - What resources would this require?

4. **Keep it concise:**
   - Target 3-5 pages for initial briefs
   - Use bullets and tables for readability
   - Link to appendices for detailed research
   - Focus on decisions, not exhaustive documentation

5. **Version control:**
   - Update the revision history table
   - Use clear version numbers (1.0, 1.1, 2.0)
   - Track major changes in the table

### Template Structure

The template includes these core sections:

1. **Executive Summary** - High-level overview for decision makers
2. **Problem** - Validation that the problem is real and worth solving
3. **Customer** - Specific target customer profile and access strategy
4. **Market Timing** - Why now is the right time for this opportunity
5. **Metrics & Success Criteria** - How we'll measure validation and success
6. **Next Steps** - Recommended validation approach and decision points
7. **Risks & Mitigation** - Critical risks and how to address them
8. **Resource Estimates** - Investment required at each stage
9. **Strategic Fit** - Alignment with company goals and existing capabilities

### Output Guidelines

- **Status field**: Use Draft while developing, Under Review when submitted to leadership
- **Priority field**: Align with Paperclip issue priority when assigned
- **Evidence-based**: Every claim should have supporting evidence or clearly marked assumptions
- **Actionable**: Include specific, concrete next steps
- **Honest**: Flag uncertainties and knowledge gaps explicitly

### Related Workflows

- All opportunity briefs should be linked to a Paperclip issue
- Store completed briefs in `../briefs/` directory
- Reference source research in the Appendix
- Update the issue with brief status and recommendations
