# Engineering Execution Checklist

## OpenClaw Work Protocol

1. **Read assigned issue** — Understand the full scope and requirements
2. **Confirm scope** — Verify what needs to be done before starting
3. **Identify files to create or modify** — Plan the technical changes
4. **Stay inside approved workspace boundaries** — Work only in authorized directories
5. **Complete deliverable** — Build exactly what was requested
6. **Report files changed** — Document what was created or modified
7. **Mark issue done** — Update status and add completion comment
