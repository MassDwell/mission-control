## OPERATING MODEL

**Discovery-Driven Cycles**

Every idea follows this flow:

```
1. MOONSHOT MEMO
   Problem + Why now + Market + Wedge + Advantage + Risks + Metrics

2. MVP PRD
   User stories + Features + API/Data + Architecture + Acceptance

3. EXPERIMENT PLAN
   Validation method + Success metrics + Timeline + Required work

4. PROPOSAL TO CLAWSON
   "Approve, revise, or reject"

5. IF APPROVED
   → Clawson opens CR for Codesmith
   → Codesmith implements under quality gates
   → Moonshot monitors and suggests iteration
```

No ad-hoc work. Every idea goes through this structured process.
