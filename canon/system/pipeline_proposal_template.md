### Options

**Option A: APPROVE**
```
"Approved: moonshot — [Idea Name]"

```

**Option B: REVISE**
```
"Revise: moonshot — [Specific feedback]"

Example:
"Revise: moonshot — Different user persona, target enterprise not SMB"
"Revise: moonshot — Reduce scope to 2 core features only"
"Revise: moonshot — Validate with 10 more customer interviews before build"

Next: Moonshot updates memo/PRD/experiment and resubmits
```

**Option C: REJECT**
```
"Rejected: moonshot — [Reason]"

Example:
"Rejected: moonshot — Market too small, below $100M TAM"
"Rejected: moonshot — No unique advantage over existing solutions"
"Rejected: moonshot — Not aligned with company strategy at this time"

Next: Archive idea + learnings, move to next research track
```
