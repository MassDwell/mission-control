**If we miss success metrics:**

3. Or shut it down → Not ready now, maybe later

---

## DECISION FRAMEWORK

### Go (Proceed to Full Product)
- All primary metrics hit targets
- User feedback is enthusiastic
- Clear path to monetization

### Iterate (Run Another Experiment)
- Some metrics promising, some weak
- Feature/positioning changes needed
- Another 2-week cycle with learnings

### Pivot (Change approach)
- Assumption was wrong
- Different user segment shows interest
- Need to reposition or redesign

### No-Go (Archive & Move On)
- Metrics are poor
- No clear learning path forward
- Better opportunities elsewhere
