- All Mission Control metrics must derive from local JSON files only
- No Supabase, no external APIs, no cached values >10 seconds

### Operator Lock Pattern
- All UI is read-only inspection + commands only
- No writes to /canon, /config, /scripts
- Commands (pause/kill/advance/spawn/assign) are reversible
- All actions logged to agent_activity.json with actor/timestamp

### Engagement Loop Design
- Three behavioral loops creating addictive iteration

- Interactive nodes + edges

- Color-coded by type (venture/workstream/agent/blocker)
- Lightweight, responsive, fast
