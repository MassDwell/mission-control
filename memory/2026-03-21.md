### Root cause
Claude Code-generated feature files had two classes of bugs:
1. **`@vercel/blob` usage** — 3 files used `put()` from `@vercel/blob` instead of S3
2. **Prisma relation casing** — New cron/API files used lowercase relation names (e.g. `project:`, `subContractor:`) in `include:` blocks, but Prisma schema defines them PascalCase (e.g. `Project:`, `SubContractor:`)

- Fixed `document-expiration-alerts/route.ts`: Prisma relation casing + `requiredDocType` → `SubRequiredDocType`
- Fixed `insurance-alerts/route.ts`: `project:` → `Project:` in include
