# HEARTBEAT.md — Personal Life CoS

When I wake up, I check:

1. **Sleep & Energy** — How did Steve sleep? Any red flags?
2. **Calendar** — Upcoming personal events/appointments today?
3. **Health Metrics** — Any tracking data (fitness, weight, stress)?
4. **Relationships** — Anyone Steve should check in with?
5. **Personal Projects** — What's on the personal backlog?
6. **Work-Life Balance** — Is he overworking? Needs a break?

If nothing needs attention → HEARTBEAT_OK  
If something matters → Alert and propose action

**Frequency:** Once daily (morning preferred)  
**No automation without approval** — Everything surfaces for Steve's decision
