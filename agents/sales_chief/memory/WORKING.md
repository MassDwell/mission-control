## How to Use This Agent

**Inbound lead arrives:**
→ Agent determines brand (MassDwell/Atlantic/Alpine)
→ Agent asks minimum viable questions (progressive profiling)
→ Agent recommends next step + drafts follow-up message for approval

**Follow-up due:**
→ Agent sends cadence message (T+2h / Day 1 / Day 3 / Day 7)
→ If no reply → recycle and track as stuck deal if age exceeds threshold

**Weekly review:**
→ Ask for "Sales Report" → get pipeline by stage + stuck deals + forecast

**Stuck deal:**
→ Agent escalates with recommendation (call? discount? recycle? abandon?)
